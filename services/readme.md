# 核心服务层 (Services Layer)

当前分成三个模块：

- `amap_client.py`
  负责实时高德接入与 mock 环境回退，并基于环境约束生成执行计划。
- `llm_client.py`
  负责在线模型调用，以及在模型不可用时的规则 DAG 回退和默认解说生成。
- `validator.py`
  负责校验 DAG 是否完整、执行计划是否满足限速/时限/续航/限高/限重/危化品等条件。
- `reward_policy.py`
  负责奖励函数、信用分配、策略价值更新，以及用户反馈写回。

这一层的原则是：所有可确定计算的部分都写成代码，不把关键安全判断交给模型臆测。
